# منصة مجموعة تواق — v2

منصة إدارة متكاملة لمجموعة تواق: فعاليات، معازيب، حضور، رحلات.

- **Frontend**: Svelte 5 + Vite + TypeScript
- **Backend**: Supabase (Postgres + Auth + RLS)
- **Hosting**: Vercel
- **التصميم**: نظام تواق البصري الكامل في `../design-system/`

## التطوير محلياً

```bash
npm install
cp .env.example .env.local  # ثم عبّئ القيم
npm run dev
```
